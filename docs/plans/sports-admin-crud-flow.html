05 — Endpoints API (Slice 2)
GET
/api/sports
Lista deportes activos ordenados por order. Sin auth.
publicPúblico
GET
/api/admin/sports
Lista todos los deportes con paginación. Query: ?search=&page=&limit=
lockSolo admin
POST
/api/admin/sports
Crea un nuevo deporte. Body: name, icon, emoji, gradient, isActive?, order?
lockSolo admin
PATCH
/api/admin/sports/:id
Actualiza cualquier campo del deporte. Todos los campos son opcionales.
lockSolo admin
DELETE
/api/admin/sports/:id
Elimina el deporte (hard delete). Los eventos existentes no se ven afectados.
lockSolo admin
