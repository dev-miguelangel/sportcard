Backend NestJS — Hello World backend/
Endpoint raíz que devuelve el estado del servicio y confirma si la base de datos está configurada.

backend/src/app.service.ts

app.service.tsimport { Injectable } from '@nestjs/common';

@Injectable()
export class AppService {
  getHello() {
    return {
      status: 'ok',
      service: 'Sport Card API',
      version: '1.0.0',
      timestamp: new Date().toISOString(),
      db: process.env.DATABASE_URL ? 'configured' : 'not configured',
    };
  }
}

backend/src/main.ts

main.tsimport { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.enableCors({
    origin: process.env.FRONTEND_URL || 'http://localhost:4200',
    credentials: true,
  });

  app.setGlobalPrefix('api');

  const port = process.env.PORT || 3000;
  await app.listen(port);
}

backend/Dockerfile

# ── Production stage ───────────────────────────
FROM node:20-alpine AS production
WORKDIR /app
ENV NODE_ENV=production
COPY package*.json ./
RUN npm ci --omit=dev
COPY --from=build /app/dist ./dist
EXPOSE 3000
CMD ["node", "dist/main"]

Frontend Angular — Hello World frontend/
Componente que llama al backend y muestra el estado. La URL de la API se inyecta en tiempo de ejecución vía nginx, lo que permite cambiarla sin reconstruir la imagen.

frontend/nginx.conf — Inyección runtime de API_URL

nginx.confserver {
    listen 80;
    root /usr/share/nginx/html;
    index index.html;

    # Genera config.js con la URL de la API en runtime
    location /config.js {
        default_type application/javascript;
        return 200 'window.__API_URL__ = "$API_URL";';
    }

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }
}

frontend/Dockerfile

DockerfileFROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine AS production
COPY --from=build /app/dist/frontend/browser /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
⚠️ Agrega <script src="/config.js"></script> en el <head> de src/index.html antes del cierre </head>.
💡 En el componente Angular lee la URL con: (window as any).__API_URL__ || 'http://localhost:3000'

Docker Compose local Prueba local
Levanta los 3 servicios localmente para verificar que todo funciona antes de subir a Coolify.

docker-compose.yml (raíz del proyecto)

docker-compose.ymlservices:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: sportcard
      POSTGRES_USER: sportcard
      POSTGRES_PASSWORD: sportcard_dev
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U sportcard"]
      interval: 5s
      timeout: 5s
      retries: 5

  backend:
    build: ./backend
    ports:
      - "3000:3000"
    environment:
      DATABASE_URL: postgresql://sportcard:sportcard_dev@postgres:5432/sportcard
      FRONTEND_URL: http://localhost:4200
      PORT: 3000
    depends_on:
      postgres:
        condition: service_healthy

  frontend:
    build: ./frontend
    ports:
      - "4200:80"
    environment:
      API_URL: http://localhost:3000
    depends_on:
      - backend

volumes:
  postgres_data:

CI/CD automático GitHub → Coolify

Activa el deploy automático para que cada git push a main dispare un nuevo deploy.

git push
→
GitHub Webhook
→
Coolify Build
→
Zero-downtime deploy

En cada servicio de Coolify:

  1. Ve a Settings → Deployments
  2. Activa Auto Deploy on Push → ON
  3. Copia el Webhook URL generado
  4. En GitHub → Settings → Webhooks → Add → pega la URL
✓ Con esto tu flujo es: editas código → git push → en 2-3 minutos está en producción automáticamente.
