Parte 6 — Despliegue automático
6.1
Activar auto-deploy en cada servicio

Para los 4 servicios de aplicación (no las bases de datos):

  1. Abre el servicio en Coolify
  2. Ve a Settings → Deployments
  3. Activa Auto Deploy on Push → ON
  4. Copia el Webhook URL generado
✅ Coolify filtra por rama automáticamente — el webhook de sportcard-dev-backend solo reacciona a pushes en dev.
6.2
Registrar webhooks en GitHub

Repositorio → Settings → Webhooks → Add webhook
Repite 4 veces (una por servicio):

GitHub Webhook
Payload URL
https://TU_VPS_IP:8000/api/webhooks/deploy/...
Content type
application/json
SSL verification
Enable ✅
Which events?
Just the push event
