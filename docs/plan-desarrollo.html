08 — Seguridad
JWT Strategy
Access token 15min + refresh token rotativo 7d. Revocación por refresh token ID.
Rate Limiting
Throttler en endpoints críticos. Límite por IP y por usuario autenticado.
Datos sensibles
Datos de salud encriptados en reposo (AES-256). Solo accesibles por el propio usuario y organizadores del evento.
Roles y permisos
Guards por recurso: organizador, participante, capitán. class-validator en todos los DTOs.
Headers de seguridad
Helmet.js activado. CORS configurado por entorno. CSP en producción.
Menores de edad
Cuenta vinculada a tutor. Tutor debe aceptar términos. Datos de menores con mayor restricción de acceso.
